# Киби

Киби — мобильная 2D-игра на Flutter для изучения основ финансовой грамотности детьми 7–11 лет.

## Что реализовано

- локальный профиль без регистрации и сбора персональных данных;
- 9 вариантов внешности Киби и 3 стадии роста;
- главный экран с балансом, накоплениями, целью и активным заданием;
- планирование бюджета;
- 8 игровых покупок;
- 5 финансовых целей;
- 15 обучающих заданий;
- достижения и история действий;
- викторина по финансовой грамотности;
- демонстрационный профиль;
- раздел для взрослого;
- сохранение прогресса на устройстве;
- работа без рекламы и покупок за реальные деньги.

## Техническая информация

Версия приложения: 1.0.0  
Номер сборки: 1  
Package name: `ru.kibi.game`  
Минимальная версия Android: Android 8.0 (API 26)

Приложение разработано на Flutter и работает офлайн.

## Запуск проекта

1. Установить Flutter stable и Android SDK.
2. Выполнить:

`flutter pub get`

3. Для запуска:

`flutter run`

4. Для создания release APK:

`flutter build apk --release`

## Архитектура

- `lib/data/game_content.dart` — игровой и обучающий контент;
- `lib/services/game_state.dart` — экономика, прогресс и сохранение данных;
- `lib/widgets/kibi_pet.dart` — отображение питомца;
- `lib/main.dart` — основные экраны и навигация.

## Графика

В проекте используются собственные графические материалы персонажа Киби, интерфейс Flutter и стандартные Material Icons.

Киби имеет 9 вариантов внешности и 3 стадии развития: малыш, подросток и взрослый.
